# Tarot-Clustering-App

This project applies natural language processing and unsupervised machine learning to the 78-card Rider-Waite-Smith tarot deck. Each card is scored across dimensions of positivity, severity, and domain relevance based on its traditional keyword meanings, then visualized on an interactive 2D map.

The core question: can we group tarot cards algorithmically based on how beneficial or harmful their meanings are — both upright and reversed?
